# BinahOne Brand Repository

## Purpose

This directory contains the official brand assets and identity
references of BinahOne.

It serves as the central repository for the company's visual
identity, brand guidelines, design references, approved logos,
exports and creative resources.

## Brand Asset Governance

The brand asset workflow follows this hierarchy:

1. **Figma** — Design source and visual reference.
2. **Logos Master** — Officially approved master logo files.
3. **Exports** — Approved derivatives generated from master assets.
4. **Public Assets** — Copies prepared for publication on the website.

## Directory Structure

- `brand-book/` — Executive brand identity documentation.
- `guidelines/` — Operational brand usage guidelines.
- `figma/` — Figma references and design resources.
- `prompts/` — Reusable AI and creative prompts.
- `logos/` — Master logos, icons, lockups and deprecated versions.
- `exports/` — Approved SVG, PNG, PDF and favicon exports.
- `iconography/` — Brand iconography.
- `illustrations/` — Official brand illustrations.
- `moodboards/` — Visual references and approved directions.
- `presentations/` — Brand presentations and institutional materials.

## Usage Rules

- Never edit files directly inside `public/logos/` as master assets.
- Published assets must originate from approved master files.
- Do not publish concepts or visual explorations that have not
  been approved.
- Do not introduce unofficial colors, typography or logo variations.
- Preserve deprecated assets for historical reference.
- Keep brand documentation and website implementation clearly separated.

## Governance Status

This repository follows the BinahOne Brand System v1.0 structure.

The existence of a directory or placeholder file does not imply
that its content has been approved.

Only explicitly approved assets and guidelines are considered
official brand resources.
